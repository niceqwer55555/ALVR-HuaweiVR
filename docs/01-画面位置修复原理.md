# 有线投屏画面位置修复原理

## 物理根因

华为 VR Glass CV10 的显示面板：

- 整屏 3200×1600，物理上是**两块 1600×1600 正方形屏**拼成；
- 左眼那块**顺时针 90°** 安装，右眼那块**逆时针 90°** 安装（排线走向所致）。

来源：`fkun1754/HwVRGlassLite` `desktop-mode/src/main.cpp:778` 的注释与 roll 补偿代码。

## 服务端原行为（问题）

`alvr/server_openvr/cpp/platform/win32/`：

1. `DesktopCapture::AcquireFrame()`：`CopySubresourceRegion` 把桌面居中 blit 到两块方形画布（`m_canvasTextures[0/1]`），**无旋转**；
2. `CEncoder::RenderCastFrame()`：`bounds={0,0,1,1}` + 单位 `pose` 直送 `RenderFrame()` → 编码。

结果：眼镜里看到的投屏画面**两眼各躺倒 90°、方向相反**。

## 修复算法（frame_roll_fix）

核心洞察：单眼画布是正方形，±90° 旋转不改变尺寸，所以能在纹理空间用纯 UV 变换完成，零性能代价。

`fr_rotate_uv(u, v, angle, &ou, &ov)`（单测验证）：

- `+90°`：`(u,v) → (1-v, u)` —— 源左上角转到右上角
- `-90°`：`(u,v) → (v, 1-u)`

`fr_eye_roll()` 给出每眼最终 roll 角（含 stage 与 override），默认 CV10 常见组合 PM = 左 +90° / 右 -90°。

4 种 stage 覆盖所有面板批次：

| stage | 左眼 | 右眼 |
|---|---|---|
| PP | +90° | +90° |
| MP | -90° | +90° |
| PM（默认） | +90° | -90° |
| MM | -90° | -90° |

`fr_next_stage()` 循环 PP→MP→PM→MM→PP，用于现场校准。

## SBS 分眼

`fr_eye_uv_rect()`：

- 左眼 UV = `[0, 0, 0.5, 1]`
- 右眼 UV = `[0.5, 0, 1, 1]`

## 接入服务端

见 `patches/画面位置修复-接入说明.md`。要点：在 `DesktopCapture::AcquireFrame()` 里把 `CopySubresourceRegion` 换成带 ±90° roll 的 UV quad blit，用 `FrameRender` 现成的顶点/像素着色器基础设施即可。

普通串流（非华为面板）设 `cfg.enabled = 0` 旁路，`fr_eye_roll()` 返回 0。
