# 服务端编译复现（本次实测通过）

> 目标：在 Linux 沙箱用 mingw-w64 交叉编译出 Windows 版 `alvr_server_core.dll`。
> 本文件记录的每一步都在 2026-11-24 实际执行成功。

## 前置条件

```bash
# Rust windows-gnu target + mingw 链接器
rustup target add x86_64-pc-windows-gnu
# ~/.cargo/config.toml
#   [target.x86_64-pc-windows-gnu]
#   linker = "x86_64-w64-mingw32-gcc"
#   ar = "x86_64-w64-mingw32-ar"
# crates 镜像（rsproxy）
#   [source.crates-io] replace-with = 'rsproxy-sparse'
#   registry = "sparse+https://rsproxy.cn/index/"
```

原仓库缺三样东西导致默认编不过，逐项处理：

## 障碍 1：缺失 `deps/wgpu-hal-huawei`

`alvr/graphics` 依赖 `wgpu-hal` 的 `huawei-vr-egl` feature，该 feature 只存在于仓库内的华为 fork（缺失）。
但源码里**没有任何 `cfg(feature="huawei-vr-egl")`**，所以只需让 cargo 解析通过。

处理：下载官方 `wgpu-hal` 24.0.0，加一个空 feature，作为本地 patch。

```bash
# 下载官方 crate
curl -sSL -o wh.crate "https://rsproxy.cn/api/v1/crates/wgpu-hal/24.0.0/download"
tar xzf wh.crate                      # -> wgpu-hal-24.0.0/
cp -r wgpu-hal-24.0.0/* <repo>/deps/wgpu-hal-local/
# 在 deps/wgpu-hal-local/Cargo.toml 的 [features] 后插入：
#   huawei-vr-egl = []
# 在根 Cargo.toml 追加：
#   [patch.crates-io]
#   wgpu-hal = { path = "deps/wgpu-hal-local" }
```

## 障碍 2：workspace 通配成员把缺 openxr 的安卓客户端也纳入解析

根 `Cargo.toml` 原本 `members = ["alvr/*"]`，`cargo` 会解析所有成员，而 `client_openxr` 依赖缺失的 `deps/openxrs-huawei/openxr`。

处理：显式列出服务端依赖链成员。

```toml
members = [
  "alvr/adb", "alvr/audio", "alvr/common", "alvr/events", "alvr/filesystem",
  "alvr/graphics", "alvr/gui_common", "alvr/packets", "alvr/server_core",
  "alvr/server_io", "alvr/session", "alvr/sockets", "alvr/system_info"
]
```

## 障碍 3：缺 OpenVR headers（`alvr/session/build.rs`）

`build.rs` 读取 `openvr/headers/openvr_driver.h` 并用正则提取属性（命中 215 项）。仓库 `openvr` 子模块为空。

处理：直接下载单个头文件（不必克隆整个仓库）：

```bash
mkdir -p openvr/headers
BASE="https://gh.dpik.top/https://raw.githubusercontent.com/ValveSoftware/openvr/master/headers/"
# 下载 openvr_driver.h (199942 B) 和 openvr.h (296217 B) 到 openvr/headers/
```

> 注意：曾有僵尸 `git clone` 进程反复删除 `openvr/` 目录，务必确认无残留 clone 进程：
> `ps aux | grep -i 'git.*openvr'`

## 编译命令

```bash
cd <repo>
cargo build --release -p alvr_server_core --target x86_64-pc-windows-gnu
```

## 编译期警告（无害）

- `alvr/server_io`：`mismatched_lifetime_syntaxes`（可加 `SessionLock<'_>`）
- `alvr/adb`：unused variable `e`（可改 `_e`）

均为上游代码风格警告，不影响产物。

## 完整 Windows 服务端（alvr_server_openvr.dll）

仓库官方脚本（已随包提供，在 `服务端-ALVR/官方编译脚本/huawei/`）：

```powershell
pwsh -NoProfile -File .\scripts\huawei\build-windows.ps1 -Configuration Release
# 内部执行：cargo xtask build-streamer --release --gpl --keep-config
```

需要 Windows + MSVC + OpenVR `.lib` + Huawei SDK，本 Linux 沙箱无法完成最终链接（仅能到 server_core 层）。已如实标注。
