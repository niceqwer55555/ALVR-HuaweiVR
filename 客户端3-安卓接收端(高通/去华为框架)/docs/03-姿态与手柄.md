# 姿态自算与双模手柄

## 一、姿态自算（Mahony 互补滤波）

`src/pose/pose.c` 是从参考仓库 `hwvrctl.c` 剥离出的**纯数学**姿态解算，不依赖任何设备：

### 陀螺积分
```
ω = [gx, gy, gz]（rad/s，机体系），dt 为采样间隔
θ = |ω| · dt
dq = [cos(θ/2), (ω/|ω|)·sin(θ/2)]
q  = q ⊗ dq        （四元数右乘）
```

### 加速度重力校正（抵消陀螺漂移）
```
ā = normalize([ax, ay, az])          仅当 0.5g < |a| < 30g 时有效
v  = q 旋转出的"上方向"在机体系的期望重力
e  = ā × v                            误差轴（叉积）
ω' = ω + kp·e + ki·∫e                 修正角速度后再积分
```
- `kp=2.0, ki=0.0`（3DoF 下位置/偏航不可观，关闭积分避免漂移累积）
- yaw 靠陀螺保持，这是标准 3DoF 行为

### 双数据源（运行时可切换）

| 源 | 入口 | 说明 |
|---|---|---|
| `POSE_SRC_PHONE_IMU` | `ga_pose_update_imu()` | 手机 TYPE_GYROSCOPE + TYPE_ACCELEROMETER，本地自算 |
| `POSE_SRC_UDP` | `ga_pose_ingest_udp_text()` | 外部报文 `"w x y z [px py pz valid]"`，4 值=3DoF，8 值且 valid=1=6DoF |

切换 API：`ga_pose_set_source(t, src)`。切到 UDP 后本地积分暂停（`ga_pose_update_imu` 直接 return），避免两源打架。

## 二、双模手柄（3DoF / 6DoF）

`src/controller/controller.c` 为每只手柄维护独立的姿态解算器 + 输入状态：

```
ga_controller_hub
  ├── pose[0]  ga_pose_tracker_t（左手）
  ├── pose[1]  ga_pose_tracker_t（右手）
  ├── st[0]    connected / dof / pose / buttons / axes
  └── st[1]
```

### 自由度切换
- `ga_controller_set_dof(h, hand, CTRL_DOF_3)`：忽略注入的位置，`position_valid=false`
- `ga_controller_set_dof(h, hand, CTRL_DOF_6)`：使用 8 值报文中的位置，`position_valid` 随 `valid` 位

### 输入映射（位掩码）
```
GA_BTN_TRIGGER / GRIP / MENU / SYSTEM / A / B
axis_x, axis_y ∈ [-1,1]（摇杆/触摸板）
trigger, grip  ∈ [0,1]
```

### Android host 侧来源
- 触摸虚拟手柄：左右半屏各一只，`onTouch` 映射按键与轴
- 蓝牙手柄：标准 Android `InputDevice` KEYCODE_* → `GA_BTN_*`（需在 `AlvrActivity` 扩展 `onKeyDown`）
- 外部 6DoF 手柄位姿：UDP 注入（与头部共端口，靠报文里的 hand 字段区分，见扩展点）

## 三、OpenXR 姿态顺序转换

核心模块存四元数为 `[w,x,y,z]`，OpenXR `XrQuaternionf` 是 `{x,y,z,w}`。桥接层 `ga_runtime_get_head_pose()` 做转换：

```
out_xyzw[0]=q.x; [1]=q.y; [2]=q.z; [3]=q.w
```

已由单测 `Runtime 桥接` 用例验证。

## 四、recenter

`ga_runtime_recenter()` 重置头部与双手柄姿态为单位四元数，位置清零，双源状态保持。绑定到 UI 按钮 `AlvrActivity.recenter()`。
