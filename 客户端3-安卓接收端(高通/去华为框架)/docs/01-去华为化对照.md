# 去华为化对照：参考仓库 vs 本工程

> 参考仓库：`niceqwer55555/HuaweiVRGlass-ALVR-Android`（一加 7T + 华为 VR Glass CV10 改造）
> 本工程：`hvr-alvr-android-generic`（通用安卓 ALVR 接收端）
>
> 逐项说明"华为依赖被替换成什么"，这是"不依赖华为 VR 框架"的可核查证据。

## 1. OpenXR 加载链路

| 环节 | 参考仓库（华为耦合） | 本工程（通用） |
|---|---|---|
| Loader | 华为定制 `libxr_loader.so`，**内嵌写死** `library_path=libvrsdk.so` | Khronos 官方 `libopenxr_loader.so` |
| Runtime 发现 | 塞一个同名 `libvrsdk.so` 骗 loader 加载 | 标准 `active_runtime.json` 声明 `libgeneric_alvr_xr.so` |
| Runtime 实现 | 自研 `mini_xr_v3.c`（伪装成华为 runtime） | `src/runtime/generic_runtime.c` + 标准 OpenXR 入口点 |
| openxr crate | `deps/openxrs-huawei/openxr`（fork，feature `huawei-loader-linked`） | crates.io 官方 `openxr` crate |
| 扩展 | `XR_HUAWEI_controller_interaction` | 标准 `XR_EXT_hand_interaction` / 标准 action 路径 |

## 2. 解码器

| 项 | 参考仓库 | 本工程 |
|---|---|---|
| 首选组件 | `OMX.hisi.video.decoder.avc`（华为麒麟专用） | `c2.qti.avc.decoder`（高通 Codec2） |
| 兼容组件 | 无（找不到就退回软解） | `OMX.qcom.video.decoder.avc`（高通 OMX） |
| 软解回退 | 静默退回 `c2.android.avc.decoder` → 纯色画面 | **禁止**；无硬解则报错（`ga_decoder_pick` 返回 NULL） |
| 平台绑定 | `use_hisi_decoder = platform.is_huawei()` | 与平台解耦，`decoder_policy` 独立模块 |

> 这正是你之前纯色问题的根因参考：参考仓库因平台写死 huawei 而选 hisi 解码器，7T 上不存在→软解→拿不到硬件帧。本工程从源头消除该分支。

## 3. 姿态来源（自己算）

| 项 | 参考仓库 | 本工程 |
|---|---|---|
| 头部姿态 | 眼镜 HID `/dev/hwvr1` → `hwvrctl pose`（Mahony）→ UDP 47110 | 同一 Mahony 算法，但输入改为**手机 IMU**（TYPE_GYROSCOPE/ACCELEROMETER），纯 C 通用实现 |
| 手柄姿态 | `dlopen("libvrpose.so")` + `PhoneControllerPose::Get`（华为库+硬编码偏移） | 每只手柄独立 `ga_pose_tracker`，IMU 自算，无 dlopen/无华为库 |
| 6DoF 位置 | 眼镜 OV580 HID 或外部 SLAM | UDP 8 值报文注入 `w x y z px py pz valid`，位置有效位自动切换 |
| 双源 | 单一路径 | `ga_pose_set_source(PHONE_IMU / UDP)` 运行时切换 |

Mahony 核心（`src/pose/pose.c`）：
```
陀螺积分:  q' = q ⊗ [cos(|ω|dt/2), axis·sin(|ω|dt/2)]
重力校正:  e = ā_measured × ā_predicted(q);  ω' = ω + kp·e + ki·∫e
yaw 不可观（重力约束），靠陀螺保持 —— 标准的 3DoF 姿态解算。
```

## 4. 手柄（3DoF/6DoF 双模）

| 项 | 参考仓库 | 本工程 |
|---|---|---|
| 手柄库 | `libvrpose.so`（华为私有） | 无；触摸虚拟手柄 + 蓝牙手柄 + 外部位姿注入 |
| 自由度 | 眼镜手柄固定 3DoF | `ga_controller_set_dof(hand, 3\|6)` 每只手柄独立配置 |
| 状态机 | `s_ctrl[hand].tracked` | `ga_controller_state_t.connected` + `pose.position_valid` |
| 输入 | 华为按键映射 | `GA_BTN_*` 标准位掩码 + 摇杆/扳机轴 |

## 5. Android 清单

| 项 | 参考仓库 | 本工程 |
|---|---|---|
| 包名 | `com.lht.huaweivr.alvr` | `com.generic.alvr` |
| 权限 | `com.huawei.android.permission.VR`、`com.huawei.vrhandle.permission.DEVICE_MANAGER` | 全部删除；仅标准网络/OpenXR 权限 |
| feature | `android.hardware.vr.headtracking required=true` | 删除（通用手机无此 feature 也能装） |
| Activity | `HuaweiVrActivity`（`com.huawei.android.vr.action.MAIN`） | `AlvrActivity`（标准 LAUNCHER） |
