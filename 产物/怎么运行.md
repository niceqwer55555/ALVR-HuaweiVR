# 怎么运行 —— 每个文件是干什么的

先看这里，避免"为什么都是 DLL"的困惑。

## 一句话结论

- **能双击运行的**：
  - `服务端/openvr/ALVR Dashboard.exe`（服务端配置界面，GUI，**内置「我的游戏」免 Steam 游戏库**）。
  - `客户端-PC/HVR-VRGlass-接收端.exe`（**PC 接收端图形界面，双击即用**，带头显/左右手柄/ALVR串流四指示灯，无需敲命令）。
- **装到手机的**：`安卓客户端/GenericALVR-arm64.apk`（同样带头显/左右手柄三设备指示灯）。
- **不能双击、必须被别的程序加载的**：所有 `.dll`。这是 **ALVR/SteamVR 的架构决定**——服务端是 SteamVR 驱动插件，不是独立程序。

---

## 为什么服务端是 DLL，不是 exe？

ALVR 服务端本质是一个 **OpenVR/SteamVR 驱动（driver）**。SteamVR 启动时由 `vrserver.exe` 按 `driver.vrdrivermanifest` 清单去加载 `driver_alvr_server.dll`，调用里面约定的 `VRDriverContext_*` 入口。这是 Valve 定义的驱动插件格式，**所有 SteamVR 驱动都是 DLL**（包括官方 Index、Vive 驱动），不存在"独立 exe 版的 SteamVR 驱动"。

所以服务端这一层的正确运行方式是：
1. 双击 **`ALVR Dashboard.exe`** —— 这是图形配置界面（真正给你操作的可执行程序）。
2. 在 Dashboard 的"安装"页注册驱动（它会把 `bin/win64/` 下的 DLL 和 manifest 注册进 SteamVR）。
3. 启动 SteamVR，SteamVR 自动加载 `driver_alvr_server.dll`，串流才真正开始。

Dashboard 只是"控制台"，串流引擎在 DLL 里由 SteamVR 托管——这就是你看到一堆 DLL 的原因，属正常现象。

## 三条完整使用路径

### 路径 A：低配电脑插眼镜，接收高配电脑的串流（本包核心用途）

1. **高配电脑（游戏机）**：装 SteamVR + 本包服务端，运行 `ALVR Dashboard.exe` 注册驱动，启动 SteamVR。
2. **低配电脑（显示端）**：插上华为 VR Glass，**双击 `客户端-PC/HVR-VRGlass-接收端.exe`** 即可。这是**单文件程序**——GUI、连接引擎、眼镜画面渲染全在这一个 exe 里，没有第二个命令行程序、没有黑窗口。点【启动串流（含画面）】后：
   - 自动连接高配电脑的 ALVR 串流；
   - 自动检测眼镜屏（3200×1600 的第二屏）并弹出全屏渲染窗口，把解码帧以 SBS 左右眼显示出来；
   - GUI 上的「ALVR 串流」指示灯在握手成功后点亮（绿=已连接，灰=等待中）。

   > `ffmpeg.exe` 已随包附带，exe 会自动找到，无需设置任何环境变量。
   > 隐藏的辅助参数（一般不用）：`--selftest`（协议自检）、`--status`（打印设备状态）、`--auto-start`（启动即自动串流，无人值守用）。
   > 手柄状态可由 `controller_status.json` 覆盖；设备/连接状态每 0.5 秒写入 `device_status.json`。
3. 两端同一局域网，按 Dashboard 提示信任设备。

### 路径 B：手机当接收端（高通/去华为框架通用版）

1. 把 `安卓客户端/GenericALVR-arm64.apk` 装到高通手机（Android 11+，如一加 7T）。
2. 手机 USB-C 插上华为 VR Glass。
3. 高配电脑跑服务端（同路径 A 第 1 步）。
4. 手机 App 通过标准 ALVR 协议连入，用高通硬解码 + 自算姿态显示 SBS 左右眼。
5. App 左上角三个指示灯实时显示头显（佩戴/电量）、左手柄、右手柄（连接/DoF/电量）——在线绿色点亮，离线灰暗；触摸左右半屏即点亮对应虚拟手柄。

### 路径 C：手机当接收端（依赖华为框架版）

`客户端2-安卓接收端(依赖华为框架)/` 只有源码，需华为闭源 SDK 才能构建 APK，本包不含其 APK。

## 文件清单与角色

| 文件 | 类型 | 能否双击 | 作用 |
|---|---|---|---|
| `服务端/openvr/ALVR Dashboard.exe` | GUI 程序 | ✅ | 服务端配置控制台 + **免 Steam 游戏库**，**从这里开始** |
| `服务端/openvr/game_library.json` | 游戏清单 | ❌ | 游戏库数据源：名称 / exe 路径 / 启动参数，可直接编辑 |
| `服务端/openvr/vrapps/` | 目录 | ❌ | 游戏注册到 SteamVR 库时生成的 `.vrmanifest` 存放处 |
| `服务端/openvr/vr_library.py` | 脚本 | ❌ | 命令行批量管理 Steam 快捷方式的 VR 库标志（可选） |
| `服务端/openvr/driver_alvr_server.dll` | SteamVR 驱动 | ❌ 由 SteamVR 加载 | 串流核心引擎 |
| `服务端/openvr/openvr_api.dll` | 运行库 | ❌ | OpenVR API，驱动依赖 |
| `服务端/openvr/vcruntime140_1.dll` | 运行库 | ❌ | VC++ 运行时 |
| `服务端/openvr/driver.vrdrivermanifest` | 清单 | ❌ | 告诉 SteamVR 怎么加载驱动 |
| `服务端/openvr/应用华为已验收配置.ps1` | 脚本 | PowerShell 7 运行 | 一键套用华为推荐参数 |
| `服务端/alvr_server_core.dll` | 核心库 | ❌ 被驱动调用 | ALVR 串流协议/编码核心（沙箱交叉编译） |
| `客户端-PC/HVR-VRGlass-接收端.exe` | 单文件程序 | ✅ | **低配 PC 接收端**：GUI + 连接引擎 + 眼镜渲染三合一，双击即用 |
| `客户端-PC/ffmpeg.exe` | 解码器 | ✅ | 随包附带 FFmpeg，核心自动查找，GUI 无需设 FFMPEG 环境变量 |
| `客户端-PC/device_status.json` | 状态文件 | ❌ | 设备状态样例，GUI 指示灯数据源 |
| `安卓客户端/GenericALVR-arm64.apk` | 安卓安装包 | 手机安装 | 通用高通接收端，三设备指示灯 |
| `画面修复模块/libframe_roll_fix.a` | 静态库 | ❌ | 编译期链接，修复投屏画面 ±90° 旋转 |

## 首次运行提醒

- Dashboard 需要 **SteamVR 已安装**（驱动要被它加载）。
- 双击 Dashboard 后，先去"安装"页注册驱动；注册后重启 SteamVR。
- 若配置被重置，用 PowerShell 7 跑 `应用华为已验收配置.ps1`，再从 Dashboard 重启 SteamVR。
- 详细图文步骤见 `服务端/openvr/README-华为VRGlass专版说明.md` 的"安装与连接"章节。
