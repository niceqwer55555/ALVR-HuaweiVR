# GenericALVR arm64 APK（2026-11-25）

## 工具链

- NDK r25c：`aarch64-linux-android21-clang`
- Build-Tools 34：`aapt2` / `d8` / `zipalign` / `apksigner`
- Platform：`android-34/android.jar`
- JDK：OpenJDK 17

## 产物

- `GenericALVR-arm64.apk`：29 KB，`com.generic.alvr`，minSdk 24 / targetSdk 34，arm64-v8a，v2/v3 签名。
- `libs/arm64-v8a/libgeneric_alvr_bridge.so`：27 KB，ELF64 AArch64，导出 15 个 JNI 符号。

## 验证

```bash
apksigner verify -v GenericALVR-arm64.apk
aapt2 dump badging GenericALVR-arm64.apk
```

结果：`Verified using v2 scheme: true`、`v3 scheme: true`；`native-code: 'arm64-v8a'`；`launchable-activity: com.generic.alvr.AlvrActivity`。

## 边界

这是平台桥/诊断壳：手机 IMU 姿态、UDP 47110 外部姿态注入、高通 H.264 解码器枚举、设备/手柄状态显示、SurfaceView 挂载点。**不含 ALVR 控制协议、视频解码与双目 SBS 渲染**，安装后不会直接出串流画面。

## 复现

```bash
cd ../../客户端3-安卓接收端(高通/去华为框架)
./scripts/build_apk.sh
```
