# 构建与运行（在你自己的 Windows 机器上）

> 本工程已在本机（Linux + Rust 1.93）通过 `cargo test`：13/13 单元测试通过。
> 但 Windows 真机渲染 / 眼镜点亮 / 与 ALVR server 互通，需按本文在你自己的 Windows + 真机验证。

## 0. 前置条件

| 组件 | 用途 | 备注 |
|---|---|---|
| Rust 1.82+（MSVC target） | 编译本工程 | `rustup target add x86_64-pc-windows-msvc` |
| FFmpeg（ffmpeg.exe） | H.264 解码 | 放到 exe 同目录，或用 `FFMPEG` 环境变量指定 |
| 上游 HuaweiVRGlass-ALVR 源码 | 提供 SBS 渲染器 | 需 `deps/huawei-desktop/` 与构建脚本 |
| MinGW-w64 | 编译渲染器 | 上游 `build-desktop-mode.ps1` 自动定位 |
| 华为 VR Glass + 6DoF 套件 IMU | 显示 + 头姿 | USB-C 直插低配 PC |

> 镜像加速（可选）：在 `%USERPROFILE%\.cargo\config.toml` 写入
> ```toml
> [source.crates-io]
> replace-with = 'rsproxy-sparse'
> [source.rsproxy-sparse]
> registry = "sparse+https://rsproxy.cn/index/"
> ```

## 1. 编译本工程

```powershell
cd hvr-alvr-win-sink
cargo build --release
# 产物：target\release\hvr-alvr-win-sink.exe
```

自检（不连网络、不碰渲染）：
```powershell
.\target\release\hvr-alvr-win-sink.exe --selftest
# 应输出：自检通过：发现包/控制帧/分片头格式正确
```

## 2. 编译 SBS 渲染器

在上游仓库目录（`HuaweiVRGlass-ALVR-main`）：
```powershell
# 先按 docs/04-渲染器补丁.md 应用补丁（新增 dm_netframe.cpp，替换视频源）
pwsh -NoProfile -File .\scripts\huawei\build-desktop-mode.ps1
# 产物：build\end\server\desktop-mode\HwVRDesktop.exe
```

## 3. 配置

把 `sink_config.json` 放在 exe 同目录（模板见工程根目录）：

```json
{
  "hostname": "HVR-SINK-PC",
  "view_resolution": [1536, 1536],
  "target_fps": 70.0,
  "ipd_m": 0.063,
  "stream_port": 9944,
  "stereo_layout": "sbs",
  "fov": [
    [-0.829, 0.829, 0.829, -0.829],
    [-0.829, 0.829, 0.829, -0.829]
  ]
}
```

- `view_resolution`：单眼分辨率。华为验收档 = 1536×1536（Runtime 上报 1552，32 对齐后）。
- `stereo_layout`：`sbs`（左右并排）或 `tb`（上下）。
- `fov`：每眼 `[left, right, up, down]`，单位是**弧度**（服务端会 tanf）。左/下必须为负：华为 95° → 半角 47.5° = 0.829 rad，tan=1.0913。不要在此填 1.0913，否则服务端会按 62.5° 半角渲染。

## 4. 运行顺序

1. **高配 PC**：启动 ALVR Dashboard，确认 SteamVR 驱动已注册、状态为"等待客户端"。
2. **低配 PC**：
   - 确认眼镜 USB-C 直插，Windows 显示设置里识别为 3200×1600 扩展屏。
   - 先启动渲染器：`HwVRDesktop.exe`（监听 127.0.0.1:9911 收帧、9912 发 IMU）。
   - 再启动接收端：`hvr-alvr-win-sink.exe`。
3. 在 ALVR Dashboard 的"设备"页信任这台低配 PC（显示为 `HVR-SINK-PC`）。
4. 观察眼镜是否出现 SBS 左右眼画面，转头确认头动跟随。

## 5. 排错

| 现象 | 检查 |
|---|---|
| `未发现 PC 串流端` | 同局域网；高配 PC ALVR Dashboard 运行中；防火墙放行 UDP/TCP 9943；`HVR-SINK` 广播可达 |
| `解码器启动失败` | ffmpeg.exe 是否在 PATH/同目录；`FFMPEG` 变量是否正确 |
| 眼镜无画面 | 渲染器是否先启动；9911 端口是否被占；用 `scripts/send_test_frame.py` 单独测渲染器 |
| 连接成功但花屏 | 两端 ALVR 版本是否一致（建议都 v20.14.1）；codec 是否 H.264；码率是否过高 |
| 头动无反应 | 渲染器补丁 C 是否生效；9912 端口；IMU 是否已标定（启动静止 300 包） |
| 只有 2DoF/画面不跟头 | 本版是 3DoF（无位置）；属预期限制 |

## 6. 端口占用速查

| 端口 | 协议 | 方向 | 用途 |
|---|---|---|---|
| 9943 | UDP | 低→高 广播 | ALVR 发现 |
| 9943 | TCP | 高→低 | ALVR 控制通道 |
| 9944（可配） | TCP | 高→低 | ALVR 视频/tracking 流 |
| 9911 | TCP | Rust→渲染器 | BGRA 帧 |
| 9912 | UDP | 渲染器→Rust | IMU 四元数 |
