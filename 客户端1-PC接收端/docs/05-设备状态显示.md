# 设备状态显示：头显与手机（电池 / 是否插上）

本轮新增。接收端现在会持续采集并显示**头显（VR Glass）**和**手机**的状态，同时把头显电池按 ALVR 标准 `Battery` 包回传给高配 PC 的 Dashboard。

## 1. 显示什么

| 设备 | 字段 | 来源（Windows） |
|---|---|---|
| 头显 VR Glass | 是否插上 | ① WMI 显示器 EDID 命中 `HWV0003/RTK2560/HUAWEI/VRGLASS/AV03/CV10`；② USB VID `12D1` |
| | EDID 名称 | `WmiMonitorBasicDisplayParams.InstanceName` |
| | USB VID:PID | `Get-PnpDevice -Class USB` 匹配 `VID_12D1`（如 `12D1:3A09` HID、`12D1:1093` DFU） |
| | 是否 DFU 模式 | PID = `1093` |
| 手机 | 是否插上 / 序列号 | `adb devices` 中状态为 `device` |
| | 型号 | `adb shell getprop ro.product.model` |
| | 电池 % / 是否充电 | `adb shell dumpsys battery`（level / status=2） |
| PC 电池 | % / 是否充电 | `Win32_Battery.EstimatedChargeRemaining / BatteryStatus` |

> 判据来自上游 `scripts/huawei/auto-vr-mode.ps1` 与 `check-wired.ps1`，与项目现有逻辑一致。
> 头显本身无电池（靠 PC USB-C 供电），所以 HMD 电池通道用「头显在线 + PC 电池/充电」代表；
> 手机电池单独显示，不混入 HMD 通道，避免 Dashboard 误显示。

## 2. 三种查看方式

### (1) 命令行单次查询
```powershell
hvr-alvr-win-sink.exe --status
```
输出示例：
```
┌─ 设备状态 ────────────────────────────────
│ 头显(VR Glass) : ● 已插上   [edid]
│   EDID: DISPLAY\HWV0003\5&abc&0&UID0
│   USB : 12D1:3A09, 12D1:1093  [DFU模式]
│ 手机           : ● 已插上   (ABCDEF123)
│   型号: LYA-AL00  电池: 73% (充电中)
│ PC 电池        : 88%
│ ALVR 串流      : ● 已连接
└──────────────────────────────────────────────
JSON: {"headset":{...},"phone":{...},...}
```

### (2) 运行时自动刷新
正常启动后，后台每 3 秒采集一次，把完整状态写到 exe 同目录的 `device_status.json`（供渲染器或外部 UI 读取），并在启动时打印一次面板。

### (3) 回传高配 PC Dashboard
连接建立后，每 5 秒通过 ALVR `ClientControlPacket::Battery`（`device_id=0` = HEAD_ID）上报 HMD 电量与插电状态。高配 PC 的 ALVR Dashboard「统计」页会显示 `battery_hmd` 与 `hmd_plugged`——**与上游手机客户端行为一致**。

## 3. 实现要点

- 模块：`src/status.rs`（`DeviceStatus` / `HeadsetStatus` / `PhoneStatus` / `PcBattery` / `StatusMonitor`）。
- 全部通过 `std::process::Command` 调外部命令或读文件实现，**不链接任何系统库** → 可交叉编译到 Windows。
- Linux 下有 sysfs 等价实现（头显走 `/sys/bus/usb/devices`、电池走 `/sys/class/power_supply/BAT0`），因此本机可跑单测验证。
- 单元测试：`cargo test` 覆盖 EDID 关键字匹配、`dumpsys battery` 解析、面板渲染、HMD 电池映射。

## 4. 前置条件

- 手机状态需要 `adb` 在 PATH（或用上游 `bin/platform-tools/adb.exe`）。没有 adb 时手机显示"未插上"，不影响其他功能。
- 头显 EDID 判定需要眼镜已 USB-C 直插且 Windows 已识别为显示器（3200×1600）。
- PowerShell（Windows 自带）用于 WMI/电池查询。
